💾 学习进度（跨设备同步）

导入的卡片、自定义钩子、掌握进度都保存在本浏览器 localStorage（刷新不丢）。
换设备流程：旧设备「📤导出备份」→ 把 HTML 文件 + 备份 JSON 都发到手机 → 手机打开 HTML 后「📥导入备份」，卡片和进度一起恢复。
💡 掌握规则：一张卡需在 3 个不同日期各还原正确一次（同一天重复正确不计数），中途点「没还原出来」会清零重来。已掌握的卡可随时「🔁 复习已掌握」拉回重背。
